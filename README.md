# Stock Market Prediction Using Linear Regression

**Project Overview**

This project uses Machine Learning and Linear Regression to predict stock closing prices based on historical stock market data. The analysis is performed using Python, with Pandas and NumPy for data handling, Scikit-learn for model training and evaluation, and Plotly for interactive stock market visualizations.
The model is trained on historical stock data using the opening price, highest price, lowest price, and trading volume as input features to predict the closing price. After training and evaluation, the model is applied to a separate TATA Steel dataset to generate predicted closing prices.

*Project Objectives*

Explore and analyze historical stock market data.
Examine data structure, descriptive statistics, and missing values.
Visualize stock price movements using interactive OHLC charts.
Build a Linear Regression model to predict stock closing prices.
Evaluate model performance using the coefficient of determination ((R^2)) and Mean Squared Error (MSE).
Apply the trained model to TATA Steel stock data.
Export predicted closing prices to a CSV file.

*Technologies and Libraries*

Python — programming language used for the project.
Pandas — data loading, manipulation, and analysis.
NumPy — numerical computing.
Matplotlib — plotting library imported in the notebook.
Seaborn — statistical visualization library imported in the notebook.
Scikit-learn — Linear Regression, train-test splitting, and model evaluation.
Plotly — interactive OHLC stock market charts.
Jupyter Notebook — development environment.
